Teacher guide / Tablets

Put the games on a tablet

Scan a code with the tablet, add the game to the home screen, and open it once while online. After that it plays without internet. Each game prints on its own page.

Free science game · SQuEACs Lab

Tadpole Trek

Guide a tadpole through a polluted pond and grow a healthy froglet brain.

squeacs.github.io/tadpole-game.html

iPad

  1. Open the Camera app, point it at the code, and tap the link that appears.
  2. When the game opens in Safari, tap the Share button (a square with an arrow). On newer iPads it may be inside the ••• menu.
  3. Tap Add to Home Screen, then Add.
  4. Open the game from the new home screen icon once while online and let it load.

Amazon Fire tablet

  1. Open the Camera app, point the back camera at the code, and tap the link that appears. (Or type the address above into the Silk browser.)
  2. When the game opens in Silk, tap the menu button (⋮).
  3. Tap Add to Home screen (some versions say Install app), then confirm.
  4. Open the game from the new home screen icon once while online and let it load.

Progress saved in the home screen game is separate from progress in the browser. Open the game online every so often to get updates.
